# Smart Currency AI V2

A one-class object detector for genuine new-series Indian ₹50 notes (front and back).

## Project layout

- `dataset/original_images/`: original photos grouped by denomination. Put your existing folders here.
- `dataset/positive_50_notes/`: Roboflow YOLO export ZIP (included in this package if supplied).
- `dataset/negative_extra/`: optional difficult background negatives.
- `dataset/processed/`: generated by the notebook.
- `notebooks/Smart_Currency_AI_V2.ipynb`: Colab training pipeline with annotation checks and training-only augmentation.
- `models/`: selected model artifacts (`best.pt`, `best.onnx`).
- `src/`: space for modular source scripts.
- `deployment/`: future web dashboard starter.
- `test.py`: local webcam test.

## Before using Colab

1. Keep your original project folder and old model files as backups.
2. Put the seven original denomination folders inside `dataset/original_images/`: `10`, `20`, `50_front`, `50_back`, `100`, `200`, `500`.
3. The notebook upload step needs a ZIP of those seven folders named `original_images.zip`.
4. The Roboflow ZIP is bundled at `dataset/positive_50_notes/My_First_Project_yolov8.zip`. Upload this file too.
5. Open `notebooks/Smart_Currency_AI_V2.ipynb` in Google Colab and run cells from top to bottom. If Colab's upload picker only accepts one file at a time, run the upload cell again for the second ZIP.

## Annotation assumptions

- The Roboflow dataset must use YOLO format, with one target class at ID `0`.
- Positive images must have non-empty label files.
- Negative images are assigned empty label files.
- The notebook checks label syntax and normalized coordinate ranges, but visual inspection of boxes is still required.

## Model outputs

The notebook exports `best.pt` and `best.onnx`. Download them into `models/` on your computer. Preserve the previous model as a baseline before replacing anything.

## Webcam

Install dependencies with `python -m pip install -r requirements.txt`, then run:
`python test.py --model models/best.onnx`

Press Q to close the webcam.

## Important limitations

- A small dataset cannot guarantee reliable rejection of every non-₹50 object.
- Keep validation and test sets unaugmented.
- Use fresh, genuine notes and varied backgrounds for independent testing.
- The dashboard is a starter placeholder, not a finished deployment.
